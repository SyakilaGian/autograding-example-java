Coba lakukan langkah-langkah ini:

Buat repository baru di GitHub (misalnya: tes-github)
Clone repository ke laptop kamu

Buat file baru:
nama.txt

Isi dengan:
Nama: (isi nama kamu)
Kelas: (isi kelas kamu)
Lakukan:
git add
git commit
git push
Pastikan file sudah muncul di GitHub

fitur-baru
Tambahkan satu file:
belajar.txt
Isi bebas tentang pengalaman belajar GitHub
Lakukan commit & push ke branch tersebut
